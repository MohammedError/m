# Web-Based Academic Research Defense — Arabic

مشروع عرض ويب تفاعلي لمناقشة بحث الماجستير:
**أثر واجهات المستخدم التكيفية على معدل احتفاظ اللاعبين في ألعاب الهاتف المحمول**

المشروع مبني بـ HTML/CSS/JavaScript فقط، ومصمم للنشر على GitHub Pages.

## الملفات
- index.html
- style.css
- script.js
- assets/ (لقطات أصلية مقصوصة من أشكال النموذج الواردة في البحث)
- README.md

## التشغيل
افتح `index.html` مباشرة في المتصفح.

## الاختصارات
- ArrowLeft / ArrowDown / Space: التالي
- ArrowRight / ArrowUp: السابق
- Home: البداية
- End: النهاية
- N: ملاحظات المقدم
- O: نظرة عامة
- F: ملء الشاشة
- Esc: إغلاق النوافذ / الخروج من الملء

## ملاحظة منهجية
لم تُنشأ أرقام إحصائية غير موجودة في البحث. النتائج عُرضت بالصياغة الاتجاهية التي يدعمها النص الأصلي.
